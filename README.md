# MAGI — 세 AI 합의 질의 시스템

에반게리온의 MAGI 화면을 본뜬 웹페이지입니다. 질문 하나를 **ChatGPT · Claude · Gemini** 세 모델에 동시에 보내고,
세 답변이 모두 모이면 **마스터 모델**이 교차검증·팩트체크해 장점만 모은 하나의 최종 답변을 만듭니다.

| 패널 | 플랫폼 |
|---|---|
| 오른쪽 아래 ·1 | OpenAI (ChatGPT) |
| 위 ·2 | Anthropic (Claude) |
| 왼쪽 아래 ·3 | Google (Gemini) |

패널에는 선택한 모델 이름만 근미래 서체(Oxanium)로 크게 표시되고(`CLAUDE OPUS 5.5·2`처럼), 연결 전에는 플랫폼 이름이 표시됩니다.

## 사용법

1. `index.html`을 최신 브라우저(Chrome, Edge, Safari, Firefox)로 엽니다. `vendor/` 폴더는 같은 위치에 둡니다.
   설치나 서버는 필요 없습니다. GitHub Pages 같은 정적 호스팅에 올려도 됩니다.
2. 세 패널 중 하나를 누르면 **접속 설정**이 열립니다. 해당 플랫폼의 API 키를 넣고 **연결**을 누르세요.
   연결되면 패널에 선택된 모델 이름이 표시됩니다.
3. 연결된 패널을 다시 누르면 그 플랫폼에서 쓸 수 있는 모델 목록이 나옵니다. 여기서 모델을 고르세요.
4. 입력창 오른쪽 아래의 **MASTER** 버튼에서 세 답변을 종합할 마스터 모델을 고릅니다.
   지금 패널에 있는 모델 세 개가 먼저 나오고, **다른 모델**을 누르면 연결된 플랫폼의 모든 모델을 검색해 고를 수 있습니다.
5. 질문을 입력하고 Enter를 누릅니다(줄바꿈은 Shift+Enter).
   - 세 AI가 답하는 동안 패널이 번갈아 반짝입니다. 답변을 마친 패널은 반짝임을 멈추고, 실패한 패널은 빨갛게 바뀝니다.
   - 모델을 바꾸거나 답이 도착하면, 그리고 가끔 무작위로 패널 글자에 글리치 효과가 지나갑니다(동작 줄이기 설정을 켠 기기에서는 꺼짐).
   - 세 답변이 모두 도착하면 마스터 모델이 종합을 시작합니다(`決議中`). 끝나면 `可決`이 표시됩니다.
   - 생성 중에는 보내기 버튼이 중단 버튼으로 바뀝니다. 오래 걸리는 AI는 답변 카드의 **건너뛰기**로 빼고 진행할 수 있습니다.
   - **다시 결의**를 누르면 이미 모인 답변으로 마스터 종합만 다시 실행합니다(마스터 모델을 바꿔 비교할 때 유용).
6. 지난 질문과 답변은 오른쪽 위 **기록**에서 다시 볼 수 있습니다(최근 30개, 이 브라우저에만 저장).

## '계정 연결'에 대해

ChatGPT Plus, Claude Pro, Gemini 구독 계정의 로그인은 외부 웹페이지에서 쓸 수 없습니다(세 회사 모두 제3자용 로그인 연동을 제공하지 않습니다).
그래서 MAGI는 각 회사의 **API 키**로 연결합니다. API 사용료는 구독과 **별도로**, 쓴 만큼 청구됩니다.
질문 하나에 AI 3번 + 마스터 1번, 모두 4번의 API 호출이 일어나고, 마스터 호출에는 세 답변이 모두 들어가므로 입력 토큰이 많습니다.

| 플랫폼 | API 키 발급 |
|---|---|
| OpenAI | https://platform.openai.com/api-keys |
| Anthropic | https://console.anthropic.com/settings/keys |
| Google | https://aistudio.google.com/apikey |

세 개를 다 연결하지 않아도 됩니다. 연결된 AI만으로 심의하고, 연결된 플랫폼의 모델 중에서 마스터를 고릅니다.

## 보안

- API 키는 브라우저에서 각 회사 API 서버(`api.openai.com`, `api.anthropic.com`, `generativelanguage.googleapis.com`)로만 직접 전송됩니다.
  중간 서버가 없고, 페이지가 읽어 오는 외부 스크립트도 없습니다(마크다운 라이브러리는 `vendor/`에 포함).
- 기본값에서는 키를 `sessionStorage`에 두어 탭을 닫으면 지워집니다. 설정의 **이 브라우저에 API 키 기억하기**를 켜면
  `localStorage`에 저장되어 다음에 열 때 자동으로 연결됩니다. 공용 PC에서는 켜지 마세요.
- 웹에 공개 호스팅하더라도 키는 방문자 각자의 브라우저에만 저장됩니다.

## 동작 방식

- 질의: OpenAI는 Responses API(`/v1/responses`), Anthropic은 Messages API(`/v1/messages`),
  Gemini는 `streamGenerateContent`를 스트리밍으로 호출합니다. 답변은 도착하는 대로 카드에 표시됩니다.
- 모델 목록: 연결할 때 각 플랫폼의 모델 목록 API를 불러와 대화용 모델만 보여 줍니다(임베딩·음성·이미지 모델은 제외).
- 마스터 프롬프트: 질문과 성공한 답변들을 넣어 다음을 지시합니다. 설정의 **마스터 프롬프트 편집**에서 바꿀 수 있습니다.
  1. 교차검증 — 답변끼리 대조해 일치·상충 부분을 가려냄
  2. 팩트체크 — 사실·수치·날짜·인용·코드를 검증하고, 틀린 내용은 바로잡고 불확실한 내용은 밝힘
  3. 종합 — 각 답변의 장점만 골라 하나의 최적 답변으로 작성하고, 끝에 짧은 검증 메모를 덧붙임
- 각 질문은 독립적으로 처리합니다(이전 대화 맥락을 이어 가지 않습니다).
